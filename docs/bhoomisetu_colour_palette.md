# BhoomiSetu Brand Colour System

## Brand Direction

**Visual identity:** Earth + Agriculture + Trust + Governance + Technology

The BhoomiSetu interface should primarily use sophisticated greens, supported by earthy browns and warm off-whites. The overall appearance should feel:

- Natural
- Professional
- Government-grade
- Modern
- Trustworthy
- Premium
- Clean
- Sustainable

Recommended visual balance:

```text
60%  Whites / Off-whites
30%  Greens
10%  Earth Browns
```

# 25. Brand Usage Rules

## DO

- Use deep forest green for brand identity.
- Use fresh green for actions and highlights.
- Use warm off-white for large surfaces.
- Use brown to communicate land and soil.
- Use light greens for backgrounds.
- Keep semantic colours consistent.
- Use generous whitespace.
- Use subtle borders.
- Use natural-looking gradients sparingly.

## DON'T

- Do not make the whole UI bright green.
- Do not use brown as the primary brand colour.
- Do not use pure white on every surface.
- Do not use many saturated colours together.
- Do not use red as a decorative colour.
- Do not use gradients on every component.
- Do not use green and brown at equal visual weight.
- Do not reduce readability for aesthetic reasons.
